# PARITY-1 — original-app parity audit

Audit date: 2026-10-12. Report only; no application changes or live provider calls.

Original baseline: `main` at `1d695a354ac3cef8814b7df91f437089a1148b5e`.
New baseline: `Extension` / starting `ext/PARITY-1` at `e449a170fdb1dcb9124c223e076b50a83d61bc35`.
Line references below are pinned to those revisions, not to concurrent workers' eventual merges. Paths are relative to the repository; `main:` explicitly identifies original code. Read `AGENTS.md`, `docs/tasks/PARITY-1.md`, and `docs/RESEARCH.md` before auditing.

The largest losses are the recognizable AI cards/title, controls for duration and instructions, and the *semantics* of clean/cinematic styles. The effect and sound registries themselves were not deleted. FX-2 restores stacks, but stock plumbing loses event detail and sampled effects remain brief. Merely finding a feature in `server/legacy.py`, a renderer schema, or a saved bespoke demo is not proof that the production UI selects it.

## Scope and interpretation

Status: ✅ same or better; 🟠 weaker (specific difference stated); 🔴 dropped from the examined new route; 🟡 legacy-only (or retained only through the legacy planning/rendering branch). A weaker UI can coexist with an intact HTTP capability. Original prompt requests are identified as requests, not guaranteed old output behavior.

Examined route: `production_frontend/src/App.tsx` → `src/api.ts` → `server/api.py` → `server/queue.py` → `pipeline/orchestrator.py` → `pipeline/extensions.py::planner_plan` → `planner/adapter.py` → `pipeline/rendering.py` → `render/engine.py`.

**Important default distinction:** `production_frontend/src/features.ts:1` defaults `planner_v2`, `full_experience`, `cards`, `transitions`, and `window_scoring` to false and music to off; `App.tsx:18` also disables captions/reactions/SAM initially. Thus a fresh UI session does **not** automatically run planner v2. The requested v2 audit evaluates enabling Story planner v2 or Full experience through the stock UI/API, not a custom demo script. Full experience enables music/cards/transitions/etc. (`pipeline/experience.py:5`), but its cards are still plain one-second titles. The legacy Gemini planner remains reachable when planner v2 is disabled (`pipeline/orchestrator.py:181`). These distinctions should be made explicit in acceptance tests.
